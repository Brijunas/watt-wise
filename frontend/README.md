# frontend

The public Watt-Wise web app: a React + TypeScript Vite PWA. The app was created in S3.1 from the Vite React TypeScript template. Commands and workflow are in [development.md](../docs/development.md).

## Docs

These docs cover `frontend/`, `admin/` and the shared `@wattwise/*` packages in `packages/`.

- [architecture.md](docs/architecture.md): stack, appearance, i18n and how the shared packages are built and consumed.
- [structure.md](docs/structure.md): folders inside an app, import direction, store and translations.
- [testing.md](docs/testing.md): test tools and where tests go.
- [conventions.md](docs/conventions.md): naming, lint rules and how the import rules are enforced.

How the frontend fits into the whole system (API contract, hosting, secrets) is in the root [technical.md](../docs/technical.md).
