# deploy

Deployment configuration for Watt-Wise: Docker Compose files per environment, PostgreSQL bootstrap, env files that hold only 1Password secret references, and later the cloudflared tunnel config. The environments are described under "Environments" in [technical.md](../docs/technical.md).

| Path                             | What it is                                                                                                                                                                                                                                                                                                                               |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `docker-compose.development.yml` | Development stack: PostgreSQL 18.6, Grafana LGTM, Mailpit and the Api, Jobs, frontend and admin from their `dev` targets, bind addresses and ports from 1Password                                                                                                                                                                        |
| `development/*.env`              | `op://` references for `op run --env-file`: `compose.settings.tpl` rendered to `deploy/.env` by `mise run setup` with `op inject` (settings, no passwords), `compose.env` for every container's passwords and app settings, through `op run` at each `up` (the apps' own reference files are `backend/src/<project>/.env.<environment>`) |
| `postgres/bootstrap.sql`         | Idempotent roles, database, schemas and privileges, run by `db-init.sh` on a new volume; sets no passwords                                                                                                                                                                                                                               |
| `postgres/db-init.sh`            | Runs in the `postgres` container, once per new database: runs the bootstrap and sets every login role's password from `<role> <password>` lines on stdin, and does nothing afterwards                                                                                                                                                    |
| `postgres/db-init-run.sh`        | `mise run db-init`: starts `postgres` and pipes the passwords from `op run` into `db-init.sh` on stdin                                                                                                                                                                                                                                   |
| `docs/postgres.md`               | Database roles, privileges, hardening and bootstrap                                                                                                                                                                                                                                                                                      |
| `docs/lgtm.md`                   | Grafana LGTM: OTLP receiver and Grafana for traces, metrics and logs                                                                                                                                                                                                                                                                     |
| `docs/development-stack.md`      | The containerized Development stack: services, settings files, published ports, volumes, reload and watch, health checks, troubleshooting                                                                                                                                                                                                |
| `docs/images.md`                 | The Api and Jobs Docker images (the Cli has none): stages, base images, build context, health check, running one                                                                                                                                                                                                                         |
| `docs/environments.md`           | The environments and where each runs; Development on a remote machine: rootless Docker, the SSH forwards, the IDE over SSH                                                                                                                                                                                                               |
| `docs/mailpit.md`                | Mailpit: catches the Development Api's email                                                                                                                                                                                                                                                                                             |

Compose files for Testing, Staging and Production, the deploy-VM provisioning and the cloudflared config come in E5C and E5D (see [epics.md](../docs/epics.md)). No secret value is ever committed; secrets come from 1Password at runtime.
