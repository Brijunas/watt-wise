# Backend test refactor: Infrastructure Stryker baseline

Per-file scores and surviving mutants of the Infrastructure run in [baseline.md](baseline.md), taken before any Infrastructure test changes (D17).

Paths are repo-relative; line:col is the mutant's start. Original is the trimmed source line. Two points on the verdicts:

- Unobservable mutants (62 rows, in [baseline-infrastructure-model.md](baseline-infrastructure-model.md)): every surviving mutant in the EF `*Configuration.cs` files and in `AppDbContext.OnModelCreating` is `coveredBy` only 8 tests, although a wrong table name would break all 72. EF builds the model once per test process and caches it, so it is built under whichever mutant (if any) is active at that moment and the cache serves every later mutant. No test can kill these under Stryker's MTP runner while the model is cached. A later batch decides whether to exclude them from `mutate` or to make each test build its own model. Until then they still count in the 37.42 % score (about 62 of the 194 survivors and uncovered mutants).
- Verdicts are drafts read from the source; none has been tried by writing the test.
