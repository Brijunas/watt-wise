# backend

The Watt-Wise .NET 11 backend: a `WattWise.sln` solution following Clean Architecture, with projects under `src/` (Domain, Application, Infrastructure, Api, Jobs) and `tests/`. The design is described in [technical.md](../docs/technical.md).

The solution doesn't exist yet. It is created in E2 (S2.1, see [epics.md](../docs/epics.md)) with `dotnet new`. It is built with the `dotnet` CLI and is never part of the pnpm workspace.
