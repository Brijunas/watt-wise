# admin

The internal Watt-Wise admin web app, for reviewing and publishing the plan catalog. What it is for is under "Admin application" in [technical.md](../docs/technical.md#admin-application).

The app was created in S3.1 from the Vite React TypeScript template. It uses the same stack and structure as `frontend/`, documented in [frontend/docs/](../frontend/docs/). Commands and workflow are in [development.md](../docs/development.md).
