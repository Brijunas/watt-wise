# admin

The internal Watt-Wise admin web app, for reviewing and publishing the plan catalog and monitoring jobs. It uses the same stack as `frontend/`; see "Admin application" in [technical.md](../docs/technical.md).

The app doesn't exist yet. It is created in E3 (S3.1, see [epics.md](../docs/epics.md)) with `pnpm create vite`, which replaces this README. Until then the folder has no `package.json`, so the pnpm workspace skips it even though `pnpm-workspace.yaml` lists it.
