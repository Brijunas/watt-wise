This is the Watt-Wise product. Its main goal is to take a user's electricity consumption data and calculate the best grid plan, the best electricity supplier plan, and the best combination of the two for that user.

The user provides a .csv file from their grid provider containing their electricity usage over whatever time period was recorded. The UI displays this as a rich, adjustable chart with filters to show electricity consumption for a specific time period.

Once electricity usage data is available, the app can show the best grid and/or supplier plan for the user. The user selects the date range to use for the decision (default: the past year from today; if there isn't enough data, the app calculates using whatever is available). The "best" plan is the cheapest one, calculated per month and/or per year, as selected by the user (default: month).

The application also provides a rich UI for browsing current supplier plans and grid plans.
